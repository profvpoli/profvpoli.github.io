# Tutorial di Programmazione

Sito statico per GitHub Pages, con il primo modulo «Matrici statiche in C++».

## Installazione

1. Apri il repository `profvpoli.github.io` su GitHub.
2. Carica **la cartella `tutorial-programmazione`** nella radice del repository (accanto a `palestra-cpp`, se esiste).
3. Verifica che GitHub Pages pubblichi dalla branch e cartella che contengono questi file.
4. Visita `https://profvpoli.github.io/tutorial-programmazione/`.

La cartella comprende una home, un indice «Strutture dati» e il modulo `strutture-dati/matrici/`.

Non richiede librerie, build, API, account, database o connessione durante l'utilizzo dopo il caricamento delle pagine. Le simulazioni sono realizzate in JavaScript, **non** eseguono realmente il codice C++.

Le dimensioni degli array di C++ sono letterali (`[3][4]`); `numeroRighe` e `numeroColonne` sono variabili usate nei cicli. I dati del tutorial sono esemplificativi.
