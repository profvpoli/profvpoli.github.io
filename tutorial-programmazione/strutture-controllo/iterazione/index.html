Iterazione: un numero alla volta

Non conosco il prossimo numero. Non devo ricordare quelli precedenti: mi bastano le variabili giuste.

1. Prima del codice: che cosa significa ripetere?

Quando arriva un numero, il programma deve fare qualcosa adesso. Dopo, quel numero non sarà più disponibile. Se voglio ricordare una proprietà dei numeri letti, devo aggiornare una variabile.

1 · Controllo se ripeto
2 · Leggo il numero
3 · Aggiorno la memoria
4 · Avanzo

Esempio: se devo sommare cinque numeri, non ricordo i numeri precedenti. Ricordo soltanto quanto vale somma.

3. Dal while al for

Se il numero di ripetizioni è noto, entrambi i cicli risolvono lo stesso problema. Il for raccoglie in un solo punto le tre parti che nel while sono separate.

while

int contatore = 0;while (contatore < 4) { // leggi ed elabora un numero contatore++;}

for

for (int contatore = 0; contatore < 4; contatore++) { // leggi ed elabora un numero}

La pagina usa quattro ripetizioni in questo esempio. Nel laboratorio puoi modificare il numero delle ripetizioni.
