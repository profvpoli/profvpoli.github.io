Matrici statiche: impara vedendo il codice in azione

Dalla dichiarazione alle elaborazioni per riga e per colonna. Segui i cicli annidati, osserva le variabili e controlla come cambiano le variabili.

01 · Comprendi

Una tabella di numeri

Una matrice è un array bidimensionale: per individuare una casella servono due indici, prima la riga e poi la colonna. Gli indici partono da zero.

int numeroRighe = 3;
int numeroColonne = 4;
int matrice[3][4];

Perché matrice[3][4] e non matrice[numeroRighe][numeroColonne]? Un array statico in C++ standard richiede dimensioni note in fase di compilazione. Le due variabili, senza const, serviranno a rendere leggibili i limiti dei cicli, ma non cambiano la dimensione della matrice. Dopo la dichiarazione possiamo scegliere tra inizializzazione nel codice e caricamento con cin. Una matrice locale non inizializzata non contiene valori utilizzabili in modo affidabile.

Seleziona una casella.

Righe e colonne

La prima riga ha indice 0, la seconda indice 1 e così via. Nella nostra matrice gli indici di riga sono 0, 1, 2, quelli di colonna 0, 1, 2, 3.

Nei dati di esempio, matrice[1][2] contiene 17.

Non confondere il numero di righe (3) con l'indice dell'ultima riga (2). L'accesso fuori dai limiti dell'array ha comportamento non definito.
02 · Attribuisci i valori

Inizializzazione oppure caricamento da tastiera?

Le due modalità servono allo stesso scopo: assegnare valori agli elementi. Nell'inizializzazione i valori sono scritti nella dichiarazione. Nel caricamento con cin l'utente li fornisce durante l'esecuzione.

04 · Carica e stampa

Visita con due cicli annidati

for (int riga = 0; riga < numeroRighe; riga++) {
    for (int colonna = 0; colonna < numeroColonne; colonna++) {
        cin >> matrice[riga][colonna];
    }
}

Il ciclo esterno sceglie una riga; il ciclo interno attraversa tutte le colonne. Per stampare, sostituisci cin con cout e inserisci cout << endl; all'interno del ciclo esterno, dopo quello interno.

07 · Confronta
Righe e colonne: cosa cambia?
Elaborazione per riga
for (int riga = 0; riga < numeroRighe; riga++) {
    int somma = 0;
    for (int colonna = 0; colonna < numeroColonne; colonna++) {
        somma += matrice[riga][colonna];
    }
    cout << somma << endl;
}
La variabile somma viene azzerata per ogni nuova riga.
Elaborazione per colonna
for (int colonna = 0; colonna < numeroColonne; colonna++) {
    int somma = 0;
    for (int riga = 0; riga < numeroRighe; riga++) {
        somma += matrice[riga][colonna];
    }
    cout << somma << endl;
}
La variabile somma viene azzerata per ogni nuova colonna.
Attenzione per massimo e minimo: all'inizio di ogni nuova riga si inizializza il valore con matrice[riga][0]; all'inizio di ogni nuova colonna con matrice[0][colonna]. Non si parte automaticamente da zero.
